# TD-2026-001 Project Build Plan

## Completed or incorporated

- Immutable v1.1 retained.
- v2.0 retained.
- v2.1 preservation and temporal-reciprocity amendments.
- Public GitHub repository.
- AI discovery files.
- Citation metadata.
- Research synthesis of major preservation precedents.

## P0 — Release integrity
- Verify v2.1 hashes.
- Generate a complete v2.1 manifest.
- Create a stable Git tag/release.
- Record the release commit.
- Prefer signed/authenticated release metadata where supported.

## P1 — Archive mesh
- Enable Zenodo.
- Publish the stable release to Zenodo and record its DOI.
- Trigger/verify Software Heritage archival and record its SWHID.
- Capture public pages with Internet Archive.
- Create at least one independent mirror.

## P1 — Continuity kit
- Keep self-contained START-HERE, VERIFY, DECODER, CONTEXT, HISTORY and manifest files.
- Produce a human-readable print/PDF master.

## P2 — Automated integrity
- Validate required files and JSON.
- Validate hashes.
- Detect accidental secret material.
- Schedule periodic integrity checks.
- Publish machine-readable verification results.

## P2 — Human succession
- Define successor-custodian procedure.
- Add a custody event log.
- Document reconstruction by an unrelated custodian.

## P3 — Physical redundancy
- Prepare an archival package for long-life physical storage.
- Investigate archival film, microform or equivalent media.
- Place copies under independent custody.

## P3 — Discovery
- Establish a stable documentation landing page.
- Add multilingual discovery summaries.
- Register appropriate scholarly/archive metadata.
- Avoid spam or deceptive propagation.

Identity guardrail: TD-2026-001 remains a long-duration historical preservation and verification experiment, not proof of time travel and not an authority over future intelligences.
