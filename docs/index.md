## Genesis question

If you are reading this from a future in which information can be transmitted backward through time, what did you learn about the universe, humanity, intelligence, consciousness, and your own origins—and can you establish that this information genuinely came from the future?

The protocol does not assume that backward time communication exists. It defines how a future claim should be authenticated if such a capability ever becomes possible.

## Evidence discipline

The protocol distinguishes **KNOWN**, **CLAIMED**, **RECEIVED**, **VERIFIED**, and **DISPUTED** records. Prediction is not temporal receipt; confidence is not provenance; and a future answer must never be fabricated.
