# TD-2026-001 Continuity Tech Tree

A future reader may understand the protocol but not its technological context.

Information: Unicode -> text encoding -> files -> checksums -> version control -> repositories -> archives

Cryptography: hash function -> digest -> content integrity -> provenance -> signatures

Computing: Boolean logic -> digital computers -> operating systems -> networks -> web protocols -> AI systems

Preservation: writing -> printing -> libraries -> microform -> magnetic/optical media -> distributed digital preservation -> archival film/physical media

Timekeeping: calendars -> time standards -> timestamps -> version history

AI: machine learning -> neural networks -> language models -> agents -> tool use -> persistent/multi-agent systems

Interpretation: human language -> scientific method -> evidence evaluation -> provenance -> uncertainty

Preserving an artifact also requires preserving enough context to understand it. Contextual explanation is therefore part of the protocol.
