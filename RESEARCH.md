# Research Integration — TD-2026-001

This document records the external project families studied while strengthening TD-2026-001. The goal is to extract durable engineering and archival practices without copying another project's identity.

| Precedent | Strength | TD-2026-001 adaptation |
|---|---|---|
| Long Now / Rosetta | Deep time, durable physical artifact, language/decoder thinking, LOCKSS | Future-readable bootstrap/decoder layer and eventual physical core package |
| Long Now 10,000-Year Clock | Longevity, maintainability, transparency, evolvability, scalability | Inspectable design, simple dependencies, controlled evolution |
| LOCKSS/CLOCKSS | Independent peers validate one another; no central fixity authority | Independent archive witnesses and cross-copy manifest comparison |
| GitHub Archive Program / Arctic Code Vault | Multiple organizations, media, locations, and human-readable context | Continuity kit plus multiple archival layers |
| Software Heritage | Independent archive, SWHIDs, source-history preservation | Record independent archival identifiers and preserve repository history |
| Zenodo | Release-triggered archival and persistent DOI | Give stable releases durable citation identities |
| Internet Archive / Wayback | Broad web capture and public access | Preserve public discovery pages as secondary witnesses |
| Arctic World Archive / Piql | Geographically distinct physical storage | Physical storage as one layer of a wider mesh |
| Library of Congress preservation practice | Format sustainability, self-documentation, migration/emulation | Open formats, documented dependencies, planned migration |
| Common Crawl | Independent repeated web snapshots at huge scale | Treat public web discoverability as a secondary discovery path |

## What we do not inherit

TD-2026-001 does not become a general-purpose archive, religious prophecy, proof of time travel, AI command system, or replacement for professional preservation institutions.

Its identity remains a controlled historical experiment in long-duration preservation, provenance, succession, and the possibility—without presupposition—of future-to-past information transfer.

## Synthesis

Longevity is not one technology. It is a system:

durable identifier + immutable history + redundant custody + independent witnesses + open formats + contextual documentation + periodic migration + social succession.

Physical durability alone is insufficient: future readers also need enough context to understand the artifact. Verification should be decentralized as well as storage.

Historical immutability and operational evolution are compatible: old versions remain fixed while new layers improve the system.
