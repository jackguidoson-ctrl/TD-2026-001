TD-2026-001 DECODER

Minimum assumptions:
- UTF-8 text
- plain text and Markdown
- JSON
- SHA-256
- Git concepts: repository, commit, branch, tag
- ordinary timestamp concepts

The protocol must remain reconstructable without GitHub, a specific AI vendor, or a particular operating system.

For multi-intelligence review records, preserve model/system identity, version, date, source revision, methodology, and hash when available.

If modern software is unavailable, the text records and manifests remain the primary reconstruction path.
